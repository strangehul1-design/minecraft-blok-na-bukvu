# Блок на букву

Рандомайзер для челленджа в Minecraft: выпадает случайная буква и время. Нужно добыть любой блок на эту букву, пока не кончился таймер.

**Играть:** https://strangehul1-design.github.io/minecraft-blok-na-bukvu/

- Буквы только те, на которые начинается хотя бы один блок (русские или английские названия).
- Время по умолчанию от 0:30 до 8:00 с шагом 30 секунд, диапазон настраивается до 15:00.
- «Начать таймер» запускает отсчёт, «Блок получен» его останавливает и показывает твоё время.
- Пробел — крутить, Enter — начать таймер / блок получен.

Всё в одном файле `index.html`, ничего устанавливать не нужно.

## Бинго-дуэль: страница для зрителя

**Смотреть игру:** https://strangehul1-design.github.io/minecraft-blok-na-bukvu/bingo.html

Показывает вживую карточку бинго-дуэли из мода «Блок на букву» (NeoForge 1.21.1): чьи клетки, счёт, таймер и ленту ходов. Нужен код комнаты из игры (`/bingo new` → код). Ходы приходят через [ntfy.sh](https://ntfy.sh).
